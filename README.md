\# Catalyst AI - Talent Scouting \& Engagement Agent



Automatically find, match, and engage candidates for your open roles.



\## Features

\- 📝 Automatic JD parsing

\- 🎯 Smart candidate matching

\- 💬 Conversational outreach simulation

\- 📊 Ranked shortlist with Match + Interest scores



\## Usage

1\. Paste a job description

2\. Click "Process Job Description"

3\. Get ranked candidates with scores



\## Scoring Logic

\- \*\*Match Score (70%)\*\*: Skill match + Experience fit

\- \*\*Interest Score (30%)\*\*: Response analysis

\- \*\*Combined Score\*\*: (Match × 0.7) + (Interest × 0.3)
